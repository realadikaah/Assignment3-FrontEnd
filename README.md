## Task Overview & Deliverables

### Part 1. Media Queries

#### Task 0. Responsive Typography
Created a webpage (`task0.html`) with headings and paragraphs. CSS media queries were implemented to dynamically scale typography font sizes for mobile, tablet, and desktop viewports.


#### Task 1. Responsive Layout with Media Queries
Designed a 3-box layout (`task1.html`, `task1.css`) using pure CSS flexbox and media queries without any external frameworks.
- Desktop: 3 boxes side by side.
- Tablet: 2 boxes in the first row, 1 box in the second row.
- Mobile: All 3 boxes stacked vertically.


### Part 2. Bootstrap Grid System

#### Task 2. Bootstrap Responsive Columns
Implemented a responsive 12-column grid layout using Bootstrap 5 (`task2.html`).
- Desktop (`col-lg-4`): 3 equal columns in one row.
- Tablet (`col-md-6`): 2 columns on the top row, 1 column below.
- Mobile (`col-12`): Fully stacked columns.


#### Task 3. Bootstrap Navigation Bar
Created a modern, responsive navigation bar (`task3.html`) using Bootstrap 5 components featuring a brand logo on the left, links on the right, and a working hamburger menu toggler for mobile devices.

### Part 3. Combined Project

#### Task 4. Responsive Portfolio Page
Developed a complete portfolio page (`task4.html`, `task4.css`) combining both CSS Media Queries and the Bootstrap 5 Grid system.
- **Header:** Bootstrap dark navbar with brand title.
- **Main Section:** 
  - Left column (`col-lg-8`): Grid of portfolio project cards.
  - Right column (`col-lg-4`): Sidebar containing personal bio and contact details.
- **Footer:** Full-width sticky-style footer.
- Custom CSS media queries were added for font-size adjustments and responsive spacing across screen resolutions.


## Brief Summary of Work Process
1. **Setting up the project structure:** Organised tasks into individual HTML and CSS files for clarity and ease of testing.
2. **Applying CSS Media Queries:** Configured breakpoints (`768px` and `991px`) for custom layout flow and responsive font sizing.
3. **Integrating Bootstrap 5:** Included Bootstrap CDN to build clean grid systems and collapsible navigation bars.
4. **Building the Portfolio Page:** Combined Bootstrap's grid system for cards and layout with custom CSS adjustments for fine-tuned responsiveness.
5. **Testing & Verification:** Tested all pages across Chrome DevTools responsive viewports (Mobile, Tablet, Desktop) to verify zero horizontal scrolling and correct layout stacking.
